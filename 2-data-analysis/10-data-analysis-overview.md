# 数据分析概述（Data Analysis Overview）



**什么是数据分析**

数据分析是指：对收集到的数据进行整理、处理、探索和解释，从中发现有价值的信息，并辅助决策的过程

```
原始数据
   ↓
整理加工
   ↓
分析探索
   ↓
发现规律
   ↓
做出判断
```

例如，一家电商公司拥有：

```
用户数据：

用户ID
年龄
地区
购买商品
购买时间
消费金额
```

通过分析发现：

```
20~30岁用户购买最多
晚上8点订单最高
某商品复购率很高
```

于是公司可以：调整营销策略、推荐商品、优化库存

**数据分析主要解决的问题**

- 发生了什么？描述性分析（Descriptive Analytics）

例如：

```
去年销售额是多少？

哪个商品销量最高？

用户数量增长多少？
```

- 为什么发生？诊断性分析（Diagnostic Analytics）

例如，发现：

```
今年销量下降20%
```

继续分析可能原因：

```
价格上涨
竞争产品出现
用户流失
市场变化
```

- 接下来会怎样？预测性分析（Predictive Analytics）

例如，根据历史数据预测：

```
下个月销量
用户流失概率
客户购买概率
```

- 应该怎么办？指导性分析（Prescriptive Analytics）

例如，模型预测：

```
某用户可能流失
```

那么可以采取措施：

```
发送优惠券
提高服务质量
推荐产品
```

**为什么 AI 需要数据分析**

机器学习的流程：

```
收集数据

↓

数据清洗

↓

数据探索

↓

特征处理

↓

训练模型

↓

评估模型
```

实际上模型训练只占其中一部分，现实项目中大量时间花在找数据、清洗数据、分析数据、构造特征等

例如，假设要训练一个预测房价的模型

| 面积 | 房间数 | 位置 | 价格  |
| ---- | ------ | ---- | ----- |
| 100  | 3      | 北京 | 500万 |
| ?    | 2      | 上海 | 300万 |
| 200  | ?      | 深圳 | 800万 |

原始数据不能直接训练，需要：

```
处理缺失值

↓

统一格式

↓

分析异常值

↓

选择有效特征

↓

输入模型
```

**数据分析的一个标准流程**

```
1. 明确问题

↓

2. 收集数据

↓

3. 数据清洗

↓

4. 数据探索和可视化

↓

5. 建立模型（可选）

↓

6. 得出结论
```

例如，现在有一个问题：为什么用户购买减少？

1.明确问题

目标：找到销量下降的原因

2.收集数据

获取：

```
用户数据
订单数据
商品数据
时间数据
```

3.清洗数据

处理：

```
缺失值
重复值
错误数据
```

4.探索数据和可视化

查看：

```
哪个地区下降最多？

哪个年龄段减少？

哪个商品影响最大？
```

画图：

```
销量趋势图

用户分布图

商品排名图
```

5.结论

例如：

```
销量下降主要来自18-25岁用户减少
原因可能是竞争产品价格更低
```

**数据分析与机器学习的区别**

|      | 数据分析           | 机器学习           |
| ---- | ------------------ | ------------------ |
| 目标 | 发现规律、辅助决策 | 训练模型、进行预测 |
| 输入 | 已有数据           | 训练数据           |
| 输出 | 结论、报告         | 预测结果           |
| 重点 | 理解数据           | 学习数据规律       |
